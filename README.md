# ระบบแผนที่ความเสี่ยงสาธารณภัยแห่งประเทศไทย 77 จังหวัด (Phasit Risk Map)

เว็บแอปพลิเคชันแสดงแผนที่ความเสี่ยงสาธารณภัยแห่งประเทศไทยครบทั้ง **77 จังหวัด (928 อำเภอ/เขต)** ตามกรอบ **แผนการป้องกันและบรรเทาสาธารณภัยแห่งชาติ พ.ศ. 2564–2570**

## คุณสมบัติหลัก
- **กรอบความเสี่ยง 4 ปัจจัย (`H, E, V, C -> R`):** ความเสี่ยงสุทธิคำนวณด้วยสมการสมมาตรบนสเกล `1.00 - 5.00`:
  $$R_{\text{ddpm}} = H^{0.40} \cdot E^{0.20} \cdot V^{0.20} \cdot (6 - C)^{0.20}$$
  พร้อมเกณฑ์เฝ้าระวังขั้นต่ำ (Safety Guardrail) ครอบคลุม **10 สาธารณภัย** และ **13 ตัวชี้วัดย่อย** (รวมการเข้าถึง Cell Broadcast และการฝึกอบรม ปภ./อปพร.)
- **มาตรฐานสี 5 ระดับผ่าน WCAG 2.1 AA:** เรียงจากน้อยไปมาก น้ำเงิน → เขียว → เหลือง → ส้ม → แดง สำหรับมิติความเสี่ยง และชุดสีมรกต 5 เฉดสำหรับมิติศักยภาพ ($C$) พร้อมโหมดลวดลายช่วยแยกสีและกรอบขยาย กทม.-ปริมณฑล และภูเก็ต
- **วิธีรวมคะแนนอำเภอสู่จังหวัด 6 กลุ่ม (7 รูปแบบ `P1`–`P6b`):** ใช้ Weighted Power Mean ผสม Weighted $\text{CVaR}_{0.20}$ แยกตามลักษณะการกระจายตัวของข้อมูล (ภัยเฉพาะจุด, แนวลุ่มน้ำ/พายุ, ภัยแผ่กว้าง, ล่อแหลม, เปราะบางต้าน Urban Masking, ศักยภาพเฉพาะถิ่นแบบ Harmonic และศักยภาพส่วนกลางเคลื่อนย้ายได้)
- **ฐานข้อมูลรายงวดเวลา (Temporal Database):** จัดเก็บข้อมูลแยกงวดรายไตรมาสครบ 928 อำเภอ/เขต พร้อมกราฟแนวโน้มย้อนหลังและสคริปต์ PostgreSQL Row-Level Security (`db/migrations/001_postgres_rls.sql`)
- **ความปลอดภัยไซเบอร์ภาครัฐและสิทธิ์ระดับอำเภอ:** ยืนยันตัวตน 2 ชั้น (RFC 6238 TOTP), เข้ารหัสรหัสผ่านด้วย `scrypt`, จำกัดสิทธิ์แก้ไขเฉพาะอำเภอในจังหวัดที่สังกัด (Server-side RBAC/ABAC), ขั้นตอนจังหวัดตรวจอนุมัติ (Maker-Checker), ป้องกัน CSRF/Brute-Force/SQLi/XSS และบันทึกตรวจสอบย้อนหลังแบบสายโซ่แฮช SHA-256

## การรันในเครื่อง (Node.js 24+)
```bash
npm install
npm test
npm run build
npm start
```
เปิดใช้งานได้ที่ `http://127.0.0.1:4173`

## การเผยแพร่บน Netlify
ระบบตั้งค่าไฟล์ `netlify.toml` และฟังก์ชัน `netlify/functions/api.mts` สำหรับ **Node.js 24 (`nodejs24.x`)** ไว้พร้อมแล้ว เมื่อส่งโค้ดขึ้นสาขา `main` ทาง Netlify จะบิลด์หน้าเว็บและ API ให้อัตโนมัติ

> **หมายเหตุข้อมูล:** ชุดข้อมูลตั้งต้นในระบบเป็นค่าฐานจำลองเชิงสถิติเพื่อประกอบการวางแผนและการสาธิต มิใช่ประกาศแจ้งเตือนภัยขณะเกิดเหตุ หากพบเหตุฉุกเฉินโปรดติดต่อสายด่วน ปภ. **1784** หรือ สพฉ. **1669** ตลอด 24 ชั่วโมง
