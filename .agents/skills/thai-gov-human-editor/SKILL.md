# คู่มือการทำงาน: บรรณาธิการภาษาราชการและขจัดกลิ่นภาษา AI (Thai Gov Human Editor)

ใช้สกิลนี้ทุกครั้งหลังสร้างหรือแก้ไขข้อความบนหน้าเว็บ บทสรุปอัตโนมัติ (NLG) คำอธิบายข้อมูล หรือเอกสารรายงาน เพื่อไม่ให้ผลงานดูเหมือนถูกสร้างโดย AI

## 1. รายการ "กลิ่นภาษา AI" ที่ต้องตรวจและแก้ไขเสมอ

| สัญญาณกลิ่น AI | ตัวอย่างที่ควรหลีกเลี่ยง | แนวทางเกลาให้เป็นภาษามนุษย์ราชการไทย |
| :--- | :--- | :--- |
| **คำเชื่อมซ้ำซากแบบ AI** | "ทั้งนี้ ข้อมูลดังกล่าวเป็น...", "สะท้อนถึงความอ่อนไหว...", "เพื่อส่งเสริมการเรียนรู้และสนับสนุนการเตรียมความพร้อม..." | ตัดคำเยิ่นเย้อขึ้นต้นประโยคตรงประเด็น เช่น "ข้อมูลชุดนี้จัดทำขึ้นเพื่อประกอบการวางแผน...", "ประเมินจากจำนวนประชากรและพื้นที่..." |
| **วงเล็บศัพท์เทคนิค/อังกฤษรกหน้าจอ** | `โหมดจำลองสถานการณ์ (What-If)`, `ก่อนหักศักยภาพ (Gross)`, `ค่าฐานจำลอง (H·E·V·C)`, `ΔR_C` | หน้าหลักใช้ภาษาไทยชัดเจน เช่น `จำลองเพิ่มศักยภาพ`, `ก่อนหักศักยภาพ`, `ค่าฐานจำลอง`, `ผลลดความเสี่ยง` (เก็บสมการและตัวแปรไว้ในหน้าต่างระเบียบวิธี) |
| **ทับศัพท์แบบแปลตรงตัว** | "แบบเรียลไทม์", "พหุภัยซ้อนทับ", "ความล่อแหลมที่เปิดรับความเสียหาย" | ใช้คำไทยที่เป็นธรรมชาติในเอกสาร ปภ. เช่น "ทันที", "หลายภัยเกิดร่วมกัน", "พื้นที่และทรัพย์สินที่อยู่ในแนวเสี่ยงภัย" |
| **ประโยคยาวเป็นพืด / บล็อกสูตรสำเร็จ** | ประโยคเดียวอัด 4–5 อนุประโยคเชื่อมด้วย "โดย... ซึ่ง... และ... ทั้งนี้..." | แยกเป็น 2 ประโยคสั้น กระชับ มีน้ำหนัก อ่านแล้วเหมือนนักวิเคราะห์แผน ปภ. สรุปให้ผู้บริหารและประชาชน |
| **หน้าตาเว็บที่ดูเหมือน Template AI** | ใส่คำอธิบายซ้ำซ้อนทุกกล่อง, ยัดตัวอักษรสัญลักษณ์และจุด `•` เกินพอดีในหัวข้อเดียว | ตัดข้อความส่วนเกิน ให้แต่ละปุ่มและหัวข้อสื่อสารได้ในคำสั้นๆ ชัดเจน |

## 2. ขั้นตอนการตรวจแก้ (Editorial Audit Checklist)
1. ตรวจทุกป้ายปุ่ม หัวข้อ เมนู และแบนเนอร์ — ตัดวงเล็บภาษาอังกฤษที่ไม่จำเป็นออก (คงไว้เฉพาะคำที่ราชการไทยใช้จริง เช่น `Cell Broadcast`, `PM2.5`, `EOC`, `N/A`, `CSV`, `WCAG 2.1 AA`, `PDPA`)
2. ตรวจบทสรุป NLG รายจังหวัด — อ่านออกเสียงในใจว่าเหมือนคนไทยเขียนหรือไม่ หากฟังดูเป็นแพตเทิร์นซ้ำแข็ง ให้ปรับโครงสร้างประโยคให้กระชับและลื่นไหล
3. ตรวจคำแนะนำ 3 ระยะและคำอธิบายตัวชี้วัด — ลบคำซ้ำ เช่น "อย่างเคร่งครัด", "อย่างต่อเนื่อง", "สะท้อน..." ที่ใช้ติดกันเกิน 2 จุด
4. ตรวจซ้ำกฎเหล็กโครงการ: **เลขอารบิก 100%**, ปราศจากคำต้องห้าม ปภ., ปราศจากคำตีตรา (`ศักยภาพต่ำ`) และไม่เรียกชุดข้อมูลจำลองว่า `ข้อมูลจริง`
